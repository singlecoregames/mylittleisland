# My Little Island 🐸🏝️

개구리가 자신의 작은 섬을 몰려오는 외계인으로부터 지키는
**뱀파이어 서바이버라이크 + 인크리멘탈** HTML5 게임.

- 이동 전용 조작 + 가끔 액티브 스킬 (Survivor-like)
- 일정 경험치마다 3지선다 업그레이드
- 런 종료 후 **노드 그래프형 영구 업그레이드** (Incremental)
- 모든 업그레이드 트리에 **섬 확장** 포함 — 런을 거듭할수록 섬이 넓어진다
- 640×360 / 32px 타일 / 웹·모바일(터치) 대응 / Phaser 3
