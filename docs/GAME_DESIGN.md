# My Little Island — 게임 개발 문서

> 개구리가 자신의 작은 섬을 몰려오는 외계인으로부터 지키는
> **뱀파이어 서바이버라이크 + 인크리멘탈** 게임

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 제목(가칭) | My Little Island |
| 장르 | Survivor-like(자동 전투 생존) + Incremental(메타 성장) |
| 플랫폼 | Web (PC 브라우저) / Mobile (터치) |
| 엔진 | HTML5 — **Phaser 3** (WebGL/Canvas) |
| 기준 해상도 | **640 × 360** (16:9, 픽셀아트) |
| 타일 크기 | **32 × 32 px** (논리 그리드 20 × 11.25 타일) |
| 캐릭터 크기 | 1 타일 이내 (≤ 32 × 32, 스프라이트 권장 24~28px) |
| 조작 | 이동 전용(가상 조이스틱) + 액티브 스킬 버튼 |
| 세션 길이 | 1런 5~15분, 종료 후 메타 업그레이드 → 다음 런 |

### 핵심 판타지
플레이어는 작은 섬에 사는 **개구리**다. 직접 공격 버튼을 누르지 않는다. 무기는
자동으로 발사되고, 플레이어는 **이동으로 위치를 잡고** 가끔 **액티브 스킬**을
쓰며 점점 강해지는 외계인 웨이브를 버틴다. 런이 끝나면 모은 자원으로
**노드 그래프형 영구 업그레이드**를 찍고, 그중에는 **섬 자체를 넓히는 업그레이드**가
반드시 포함되어 — 플레이 공간과 방어 시설을 지을 땅이 런을 거듭할수록 커진다.

## 2. 게임 루프

### 2.1 매크로 루프 (메타 / 인크리멘탈)
```
[메타 화면: 노드 그래프 업그레이드]
        │  (영구 재화 소비)
        ▼
   [런 시작 — 섬 위에 스폰]
        │
        ▼
   [전투: 웨이브 생존 + 레벨업 3지선다]
        │  (사망 또는 보스 클리어)
        ▼
   [정산: 영구 재화 획득]
        │
        └──────► (메타 화면으로 복귀)
```

### 2.2 마이크로 루프 (런 내부)
```
이동 → 자동 공격이 적 처치 → 경험치 젬 드랍 → 흡수
  → 경험치 게이지 충전 → 레벨업 → 3지선다 업그레이드 선택
  → 더 강한 웨이브 → (생존하면 반복 / 죽으면 정산)
```

플레이어 입력은 **이동 + 액티브 스킬 발동** 두 가지뿐. 공격·타게팅·발사는 전부 자동.

## 3. 기술 스택

### 3.1 엔진: Phaser 3 (권장)
- WebGL 우선 + Canvas 폴백 → 구형 모바일 호환.
- `pixelArt: true` 로 32px 타일/스프라이트의 선명한 확대.
- `Scale.FIT` + `autoCenter` 로 640×360 캔버스를 화면에 레터박스 스케일.
- Arcade Physics(AABB)면 충분 — 발사체·적·플레이어 충돌은 원/사각 판정.
- 터치/포인터 입력 기본 지원, 멀티터치 가능(조이스틱 + 스킬 버튼 동시).

> 대안: PixiJS(렌더만, 게임 로직 직접 구현) / Kaboom.js(러닝커브 낮음, 대규모
> 엔티티 성능 부담). Survivor-like는 화면에 수백 개 엔티티가 뜨므로,
> 물리·풀링·씬 관리가 갖춰진 Phaser 3가 가장 무난하다.

### 3.2 빌드 / 언어
- **TypeScript** (타입 안전, 업그레이드/데이터 테이블이 많아 권장).
- **Vite** 번들러 (빠른 HMR, 정적 배포 산출물).
- 정적 호스팅(GitHub Pages / Netlify / itch.io)으로 배포 가능.

### 3.3 성능 목표
- 60 FPS 유지 기준 동시 적 200~400체.
- **오브젝트 풀링** 필수: 적·발사체·경험치 젬·데미지 텍스트.
- 공간 분할(그리드 해싱)로 충돌 후보 축소.

## 5. 전투 메커닉

### 5.1 이동
- 가상 조이스틱(모바일) / WASD·방향키(PC)로 8방향 이동.
- 개구리 테마 살리기: 기본 이동 + (옵션) **점프 대시** 액티브 스킬.
- 이동 속도는 업그레이드 대상 스탯.

### 5.2 자동 무기 시스템
무기는 슬롯(최대 6개)에 장착. 각 무기는 독립 쿨다운으로 자동 발동.

| 무기 예시(개구리 테마) | 동작 |
| --- | --- |
| 혀 채찍(Tongue Lash) | 가장 가까운 적 방향으로 짧게 뻗는 근접 타격 |
| 침방울(Spit Bubble) | 일정 주기로 가까운 적에게 발사체 |
| 연꽃 가시(Lotus Spikes) | 플레이어 주변 원형 장판 데미지 |
| 파리 유도탄(Fly Homing) | 유도 발사체, 적 추적 |
| 우박/번개 등 | 화면 랜덤 위치 낙하형 광역 |

- 무기 스탯: 데미지 / 쿨다운 / 투사체 수 / 관통 / 범위 / 투사체 속도 / 지속시간.
- 레벨업 시 무기 신규 획득 또는 기존 무기 레벨업.

### 5.3 액티브 스킬 (수동 발동)
- 1~2개 슬롯, 쿨다운 기반. 버튼/단축키로 수동 발동.
- 예: **점프 대시**(짧은 무적 이동), **개굴 포효**(주변 넉백+스턴),
  **비구름 소환**(지정 범위 지속 광역).
- "가끔 액티브 스킬을 쓴다"는 컨셉 충족 — 평소엔 이동, 위기 때 스킬.

### 5.4 경험치 & 레벨업
- 적 처치 → 경험치 젬 드랍 → 일정 반경 내 자동 흡수(흡수 반경은 업그레이드 대상).
- 게이지 충전 시 레벨업 → **게임 일시정지 + 3지선다 업그레이드 카드**.
- 레벨업 요구 경험치는 레벨마다 증가(예: `base * level^1.2`).

### 5.5 3지선다 업그레이드(런 내 한정)
- 무작위 3장(가중치·중복 방지·이미 만렙인 항목 제외).
- 카테고리: 신규 무기 / 무기 강화 / 패시브 스탯 / 액티브 스킬 / 임시 시설.
- 리롤·밴(메타 업그레이드로 해금) 같은 편의 기능 확장 여지.
- **런 내 업그레이드는 런 종료와 함께 소멸**(메타 업그레이드와 구분).

## 6. 섬 확장 시스템 ★핵심 차별화

> 일반 Survivor-like는 무한 평원에서 싸우지만, 이 게임은 **유한한 섬**이 무대다.
> 섬 가장자리는 바다(낙하/이동 불가). 외계인은 바다 쪽 또는 섬 가장자리에서 침입.
> **섬을 넓히는 것**이 메타 성장의 중심축이며, 모든 업그레이드 트리에 반드시 포함된다.

### 6.1 섬의 표현
- 섬은 **타일 그리드**(예: 시작 8×8 타일)로 정의. `0=바다, 1=땅`.
- 땅 위에서만 이동/시설 배치 가능. 바다 타일로는 못 감(보이지 않는 벽 또는 추락 패널티).
- 카메라·미니맵이 섬 경계를 인지.

### 6.2 확장 방식 (두 층위)
1. **메타 확장(영구):** 노드 그래프에서 "섬 확장" 노드를 찍으면 시작 섬 크기가
   영구히 커진다. (예: +1링의 땅 타일, 새 구역 해금)
2. **런 내 확장(임시, 선택):** 특정 레벨업/시설로 런 도중 일시적으로 땅을
   넓혀 전술적 공간 확보(런 종료 시 리셋).

### 6.3 방어 시설(섬 위 배치)
넓어진 땅에 시설을 배치 → 자동 방어/유틸 제공.

| 시설 | 효과 |
| --- | --- |
| 포탑(Lily Cannon) | 자동 사거리 내 적 사격 |
| 가시 울타리(Reed Fence) | 적 이동 저지/감속, 접촉 데미지 |
| 경험치 정원(XP Garden) | 주변 경험치 흡수 반경/획득량 증가 |
| 치유 연못(Heal Pond) | 위에 있으면 체력 재생 |
| 등대(Beacon) | 시야/적 스폰 경고, 광역 버프 |

- 시설은 **타일 스냅** 배치. 확장된 땅이 많을수록 배치 자유도/방어선 두께 증가.
- 시설 해금·강화도 노드 그래프 + 런 내 3지선다 양쪽에서 가능.

### 6.4 섬 확장의 게임 디자인 의의
- 인크리멘탈의 "수치가 우상향" 쾌감을 **공간의 확장**으로 시각화.
- 넓은 섬 = 더 많은 시설 = 더 강한 방어선 = 더 깊은 웨이브 도달 → 더 많은 영구 재화.
- 단, 넓을수록 방어할 가장자리(둘레)도 길어져 **리스크/리워드** 트레이드오프 존재.

## 7. 메타 진행 — 노드 그래프 업그레이드

### 7.1 구조
- **노드 그래프**(스킬 트리): 노드 = 영구 업그레이드, 엣지 = 선행 조건.
- 런 정산에서 얻은 **영구 재화(예: 호박석/별조각)** 로 노드 잠금 해제.
- 노드는 다음 카테고리를 포괄(요구사항 명시):

| 카테고리 | 예시 노드 |
| --- | --- |
| **섬 확장** ★필수 | 시작 섬 +1링, 새 지형 해금, 시설 슬롯 +1 |
| 유틸 | 시작 경험치 보너스, 흡수 반경, 재화 획득량, 리롤 횟수 |
| 공격력 | 기본 데미지/투사체 수/쿨다운 감소, 신규 무기 해금 |
| 방어 시설 | 신규 시설 해금, 시설 레벨 상한, 시설 쿨다운 |
| 생존 | 최대 체력, 체력 재생, 부활 1회, 이동속도 |
| 액티브 스킬 | 신규 액티브 해금, 액티브 슬롯 +1, 쿨다운 감소 |

### 7.2 디자인 원칙
- **섬 확장 노드는 트리의 중심 간선**에 두어, 진행하면 자연히 섬이 커지도록 배치.
- 분기 선택(공격 특화 vs 방어 특화 vs 유틸)으로 빌드 다양성.
- 일부 노드는 **신규 콘텐츠 해금**(무기/시설/적), 일부는 **수치 강화**(반복 투자).
- 데이터 주도(JSON) — 노드 추가/밸런싱이 코드 수정 없이 가능하게.

## 8. 적 · 웨이브 디자인

### 8.1 외계인 타입(예시)
| 타입 | 특징 |
| --- | --- |
| 잡몹 슬라임형 | 느리고 약함, 다수 |
| 돌격형 | 빠르게 직진, 체력 낮음 |
| 탱커형 | 느리고 단단, 넉백 저항 |
| 원거리형 | 멈춰서 투사체 발사 |
| 분열형 | 죽으면 작은 개체로 분열 |
| 비행형 | 바다 위로도 접근(섬 가장자리 위협) |
| 보스 | 웨이브 분기점, 처치 시 큰 보상 |

### 8.2 스폰 / 난이도 곡선
- 시간 기반 스폰 테이블(런 경과 시간에 따라 종류·밀도·체력·속도 상향).
- 가장자리/바다 방향에서 섬 안쪽으로 진입 → 플레이어는 중앙 거점 방어.
- 일정 간격 **엘리트/보스** 등장 → 클리어 시 보물상자(런 내 업그레이드/재화).

## 9. 업그레이드 데이터 모델

### 9.1 런 내 업그레이드(3지선다 카드)
```ts
interface RunUpgrade {
  id: string;
  name: string;
  category: 'weapon' | 'weaponLevel' | 'passive' | 'active' | 'structure';
  description: string;
  maxLevel: number;
  weight: number;            // 등장 가중치
  prerequisites?: string[];  // 선행 업그레이드
  apply(state: RunState): void;
}
```

### 9.2 메타 노드
```ts
interface MetaNode {
  id: string;
  name: string;
  category: 'island' | 'util' | 'attack' | 'structure' | 'survival' | 'active';
  cost: number;              // 영구 재화
  position: { x: number; y: number }; // 그래프 좌표
  requires: string[];        // 선행 노드
  effects: MetaEffect[];     // 시작 스탯/해금에 반영
  isIslandExpansion?: boolean;
}
```

### 9.3 섬 상태
```ts
interface IslandState {
  tiles: number[][];         // 0=바다, 1=땅
  width: number; height: number;
  structures: PlacedStructure[];
}
```

## 10. UI / UX · 터치 컨트롤

### 10.1 HUD (640×360 안에 배치)
- 좌상단: 체력 바 / 레벨 / 경험치 게이지.
- 상단 중앙: 경과 시간 / 웨이브.
- 우상단: 보유 무기·패시브 아이콘.
- 하단: 모바일 가상 조이스틱(좌) + 액티브 스킬 버튼(우).

### 10.2 터치 컨트롤
- **가상 조이스틱**: 화면 좌측 절반 터치 시 그 지점 기준 동적 생성(고정형 옵션도).
- **액티브 스킬 버튼**: 우측 하단 1~2개, 쿨다운 링 표시.
- **멀티터치**: 이동 + 스킬 동시 입력 지원.
- PC: 키보드(이동) + 마우스/스페이스(스킬) 병행.
- 입력 추상화 레이어(`InputController`)로 PC/모바일 통합.

### 10.3 반응형
- `Scale.FIT`로 640×360 비율 유지 + 레터박스.
- 안전 영역(노치) 고려해 HUD 여백 확보.
- 세로/가로: 가로(landscape) 권장, 세로 시 회전 안내.

## 11. 아키텍처 / 씬 구성

### 11.1 Phaser 씬
```
BootScene      → 설정/스케일 초기화
PreloadScene   → 에셋 로드, 로딩바
MetaScene      → 노드 그래프 업그레이드 화면(런 사이)
GameScene      → 실제 전투 런
UIScene        → HUD/조이스틱(GameScene 위 오버레이)
LevelUpScene   → 3지선다 카드(일시정지 오버레이)
ResultScene    → 런 정산/재화 지급
```

### 11.2 시스템(ECS-lite 또는 매니저 패턴)
- `EnemySpawner`, `WeaponSystem`, `ProjectilePool`, `XPSystem`,
  `UpgradeSystem`, `StructureSystem`, `IslandManager`, `SaveManager`.
- **오브젝트 풀**: 적/발사체/젬/데미지텍스트.
- **세이브**: `localStorage`(메타 진행/재화/해금/설정). 추후 클라우드 동기화 여지.

### 11.3 데이터 주도 설계
- `data/weapons.json`, `data/enemies.json`, `data/runUpgrades.json`,
  `data/metaNodes.json`, `data/waves.json`.
- 밸런싱을 코드와 분리 → 반복 튜닝·확장 용이.

## 13. 개발 로드맵 (마일스톤)

### M0 — 셋업
- Vite + TypeScript + Phaser 3 부트스트랩, 640×360 픽셀 스케일, 빈 GameScene.

### M1 — 코어 무브먼트 & 섬
- 섬 타일 그리드 렌더, 플레이어 이동(키보드), 카메라 추적/경계 클램프.

### M2 — 전투 코어
- 적 스폰 + 추적 AI, 자동 무기 1종, 충돌/데미지, 오브젝트 풀, 사망 처리.

### M3 — 성장 루프
- 경험치 젬/흡수, 레벨업, 3지선다 업그레이드 카드, 무기·패시브 다수.

### M4 — 터치 & 모바일
- 가상 조이스틱, 액티브 스킬 버튼, 반응형 스케일, 멀티터치.

### M5 — 메타/인크리멘탈
- ResultScene 재화 정산, MetaScene 노드 그래프, **섬 확장 노드**, SaveManager.

### M6 — 시설 시스템
- 섬 위 시설 배치(타일 스냅), 포탑/울타리 등, 시설 해금·강화.

### M7 — 콘텐츠 & 밸런스
- 적 다양화, 보스, 웨이브 테이블, 무기/노드 확장, 난이도 곡선 튜닝.

### M8 — 폴리시 & 배포
- 사운드/이펙트, 메뉴/설정/저장, 성능 최적화, 정적 호스팅 배포.
